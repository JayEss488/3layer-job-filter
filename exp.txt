Live Production System Troubleshooting & Bug Bypassing (LSE Job Portal)
Context: While submitting a professional application on the London School of Economics (LSE) recruitment portal, encountered a critical system-wide freeze where the "Apply" and "Save" buttons.
Root Cause Analysis: Inspected the live page layout and browser Developer Tools console to diagnose the failure. Identified a major architectural oversight by the platform's development team: an HTML input element had been assigned a malformed ID containing literal spaces and punctuation (id="RadBtnHdnAre you a current member of LSE staff?"). Because spaces denote child hierarchies in jQuery, the selector engine threw a fatal syntax exception.
Resolution Strategy (Bypass Development): * Initially attempted script injection to load a passive backup engine (jquery-ajax-unobtrusive) over local memory, discovering a strict Content Security Policy (CSP) blocking external CDN calls.
Wrote and invoked a low-level browser prototype call (HTMLFormElement.prototype.submit.call) to force data transmission directly to the server endpoint, entirely bypassing the platform's broken event listeners.
Outcome: Successfully forced a raw data packet submission to the server backend without data loss or corruption, successfully advancing the application to the next staging screen. Followed up by compiling a professional, highly granular technical bug report sent to the LSE HR/Technical teams detailing the line-by-line cause and outlining a sanitized camelCase/hyphenated string implementation fix.
