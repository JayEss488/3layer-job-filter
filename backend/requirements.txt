# Sign in with Apple. Apple publishes no tokeninfo-style endpoint (the way
# Google does), so an Apple ID token has to be verified LOCALLY against their
# JWKS -- RS256 signature, issuer, audience and expiry. That is the one part of
# this app where a subtle mistake is an authentication bypass rather than a bad
# job match, so it uses a maintained library instead of hand-rolled crypto.
# The [crypto] extra pulls `cryptography`, which is required for RS256.
